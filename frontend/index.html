Technical Architecture & Security

HDTalk is architected with modern distributed web standards:

  • Frontend: React 18, Vite 5, Tailwind CSS, Lucide Icons, and Web Audio API synthesizer.
  • Real-Time Transport: Socket.IO 4.x WebSocket channels with low-overhead binary event frames.
  • Media Streams: WebRTC Mesh signaling with RTCPeerConnection, STUN/TURN traversal, and DTLS-SRTP 256-bit media encryption.
  • Security Controls: Salted bcrypt password hashing, 30-day JWT session authentication, strict CORS origins, rate limiters, and NoSQL injection sanitizer.
